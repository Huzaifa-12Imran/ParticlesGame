# Particles Physics Game

A 3D particle physics simulation and interactive game built using **Three.js** and **Vite**.

## Overview

This project is a high-performance WebGL-based application that explores particle physics mechanics in a 3D environment. It uses Three.js for 3D rendering and Vite for lightning-fast development and optimized production builds.

## Features

- **Three.js Graphics**: Smooth 3D graphics rendering in the browser.
- **Particle Physics**: Custom particle physics, interactions, and dynamic motion.
- **Vite Build System**: Fast hot module replacement (HMR) and optimized build for production.

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/Huzaifa-12Imran/ParticlesGame.git
   cd ParticlesGame
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```
   *The server will typically start on `http://localhost:5173/`.*

## Build for Production

To create a production-ready bundle, run:

```bash
npm run build
```

This will output the optimized static assets into the `dist` folder. You can preview the production build using `npm run preview`.

## Tech Stack

- **HTML5 Canvas** / WebGL
- **Three.js** (`^0.183.2`)
- **Vite** (`^6.0.0`)
- **JavaScript (ES6+)**
